# wx4py-mcp 功能整理（2026-06-07）

## 一、项目定位

基于 **wx4py** 的微信自动化方案，接入 WorkBuddy / Cursor MCP，实现：

- 私聊 / 群聊 **发消息**
- 私聊 / 群聊 **AI 轮询监听自动回复**
- 私聊 **语音 / 视频通话**（聊天指令触发）
- 优先 **左侧会话列表** 打开聊天，减少 Ctrl+F 搜索与窗口反复开关

**项目路径：** `E:/webchat-ai`  
**Python：** `C:/Users/Administrator/AppData/Local/Programs/Python/Python311/python.exe`  
**AI 模型：** WorkBuddy / mmx `MiniMax-M2.5`（`~/.mmx/config.json`）

## 三、核心模块

```
wx4py_mcp/
├── open_chat.py          # 打开会话：当前聊天 → 列表点击 → 搜索（一次）
├── last_message.py       # 读最后一条 + 左灰/右绿判断 + 语音/图片
├── voice_message.py      # 语音转文字（微信原生菜单）
├── image_message.py      # 图片截图（缩略图优先）
├── vision_client.py      # MiniMax-M3 视觉 API
├── call_control.py       # 标题栏通话按钮 → 语音/视频
├── listen_control.py     # 停止/恢复/通话指令识别
├── state_store.py        # 监听状态持久化
├── wechat_lock.py        # 跨进程 UI 锁
├── workbuddy_model.py    # AI 配置与 prompt
├── poll_private_chat.py  # （scripts）私聊监听主程序
└── poll_group_chat.py    # （scripts）群聊监听主程序
```

### 打开会话逻辑（`open_chat_smart`）

1. 激活微信（可见则仅置前，不反复托盘恢复）
2. **当前聊天已是目标** → 直接继续
3. **左侧列表查找目标** → 点击切换
4. **列表找不到** → Ctrl+F 搜索 **一次**

### 监听逻辑（私聊 / 群聊相同）

1. 每 N 秒轮询（默认 15s）
2. 只读 **最后一条可见消息**
3. **左侧灰色** = 对方/群友 → 可回复
4. **右侧绿色** = 自己 → 跳过
5. `__last_replied__` 防重复回复；`__outgoing__` 防 echo 循环
6. 「停止监听」→ 回复确认 → **进程退出**

## 八、注意事项

1. **联系人 / 群名** 必须与微信显示完全一致（大小写敏感），如 `Air`、`测试群1`
2. 微信窗口宜保持可见，最小化到托盘时可能需一次 activate
3. **不要同时跑** 两个监听进程（共用 UI 锁）
4. 停止监听后需 **重新执行启动脚本** 才能继续轮询
5. 私聊与群聊监听 **分开启动、分开测试**
