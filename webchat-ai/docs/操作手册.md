## 一、使用前准备

### 1.1 环境检查

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11 |
| 微信 | PC 版已登录，主窗口可正常打开 |
| Python | 3.11（默认路径见下） |
| AI 配置 | `E:/webchat-ai/config/ai-config.json` 或本机 mmx 配置 |

**Python 路径（默认）：**

```
C:\Users\Administrator\AppData\Local\Programs\Python\Python311\python.exe
```

### 1.2 首次安装（只需做一次）

```powershell
cd E:/webchat-ai
pip install -e .
```

### 1.3 AI 模型配置（只需做一次）

```powershell
# 从模板生成配置文件
python E:/webchat-ai/scripts/ai-config.py --init

# 编辑并填入 api_key
notepad E:/webchat-ai/config/ai-config.json

# 检查是否生效
python E:/webchat-ai/scripts/ai-config.py --status
```

### 1.4 联系人名称

- 必须使用微信里的**备注名**或**显示名**，大小写、空格要完全一致  
- 示例：`Air`、`coco`、`娟子`、`测试群1`  
- 不确定时，先在微信左侧会话列表里确认名称

## 二、一键开启监听（推荐）

### 2.1 方式一：双击批处理（最简单）

**文件位置：** `E:\webchat-ai\start-all.bat`

**操作步骤：**

1. 确保微信 PC 版已登录  
2. 双击 **`start-all.bat`**  
3. 黑色命令行窗口出现，按提示操作：

```
========================================
  WebChat AI - 开启监听
========================================

请输入微信备注名（多个用逗号分隔）
示例: Air,coco

监听对象: _
```

4. 输入要监听的联系人，例如：

   ```
   监听对象: coco
   ```

   或多个：

   ```
   监听对象: Air,coco,娟子
   ```

5. 回车后显示确认：

   ```
   即将监听: coco
   启动后会向 TA 发送 AI 小宝 自我介绍
   ```

6. 可选：输入群聊名称（不需要则直接回车跳过）

   ```
   群聊名称（可选，直接回车跳过）: 测试群1
   ```

7. 程序自动执行：
   - 打开微信，向目标用户发送自我介绍  
   - 在后台最小化窗口启动监听进程  

8. 看到 **`[完成] 已在后台最小化窗口运行`**，按任意键关闭窗口即可  

**自我介绍内容（自动发送）：**

> 你好！我是AI小宝，你可以跟我唠唠嗑。如果不想让我继续回复了，就发送「停止监听」。

### 2.2 后台窗口说明

启动成功后，任务栏会出现最小化窗口，标题类似：

| 窗口标题 | 含义 |
|----------|------|
| `WebChat-私聊-coco` | 正在监听私聊 coco |
| `WebChat-私聊-Air,coco` | 同时监听多个私聊 |
| `WebChat-群聊-测试群1` | 正在监听群聊 |

可点开窗口查看实时日志；**不要关闭该窗口**，关闭等于停止监听。

### 2.3 方式二：静默启动（不交互，适合脚本）

**文件：** `E:\webchat-ai\start-all-quiet.bat`

```bat
start-all-quiet.bat coco
```

- 不弹出输入框，直接监听指定联系人  
- 同样会发送 AI 小宝自我介绍  
- 无完成提示窗口  

### 2.4 方式三：PowerShell 单联系人

```powershell
powershell -File E:/webchat-ai/scripts/listen-wechat.ps1 coco
```

- 适合只监听一个人  
- **不会**自动发送自我介绍（需手动发或使用 `start-all.bat`）  
- 启动时会自动读取最后一条对方消息并补回复

## 三、一键停止监听

### 3.1 方式一：双击批处理（推荐）

**文件位置：** `E:\webchat-ai\stop-all.bat`

**操作步骤：**

1. 双击 **`stop-all.bat`**  
2. 程序自动：
   - 终止所有私聊监听进程  
   - 终止所有群聊监听进程  
   - 将联系人/群标记为「已暂停」  
3. 看到 **`[完成] 已全部停止私聊与群聊监听`**，按任意键关闭  

### 3.2 方式二：静默停止

**文件：** `E:\webchat-ai\stop-all-quiet.bat`

- 双击或脚本调用，无 pause 提示  
- 效果与 `stop-all.bat` 相同  

### 3.3 方式三：在微信里停止

让被监听的对象发送：

```
停止监听
```

AI 小宝会回复确认，**监听进程自动退出**。

> 注意：这种方式只停止当前运行的监听进程；若之后要重新开启，需再次运行 `start-all.bat`。

### 3.4 方式四：只停止指定联系人

```powershell
powershell -File E:/webchat-ai/scripts/stop-wechat.ps1 coco
```

```powershell
# 或 Python
python E:/webchat-ai/scripts/stop_listen.py --contacts coco
```

## 四、监听过程中会发生什么

### 4.1 启动阶段

```
输入联系人 → 发送自我介绍 → 清除暂停标记 → 启动后台监听
                                    ↓
                          读取最后一条对方消息（补回复）
                                    ↓
                          进入每 15 秒轮询
```

### 4.2 收到消息后的处理

| 消息类型 | 处理方式 |
|----------|----------|
| 文字 | AI 小宝自动回复（带最近 10 条对话记忆） |
| 语音 | 微信「语音转文字」→ AI 回复 |
| 图片 | MiniMax-M3 识别 → 整理成文字 **直接发回** |
| 文档 | 下载解析（txt/pdf/docx）→ 整理成文字 **直接发回** |
| 系统消息 | 忽略 |

### 4.3 对话记忆

- 路径：`C:\Users\Administrator\.wx4py-mcp\memory\private\{联系人}.json`  
- 默认保留最近 **10 条**（用户 + AI 合计）  
- 关闭记忆：设置环境变量 `WX4PY_MEMORY_SIZE=0`

## 五、微信内控制指令

被监听的对象可在微信里发送以下指令：

| 指令 | 效果 |
|------|------|
| `停止监听` | 停止自动回复，监听进程退出 |
| `停止自动回复` / `别自动回复` | 同上 |
| `开始监听` / `恢复监听` | 恢复自动回复（进程仍在时） |
| `视频通话` | 私聊专用，自动发起视频通话 |
| `语音通话` | 私聊专用，自动发起语音通话 |

## 六、命令行 / 脚本方式

### 6.1 批处理文件一览

| 文件 | 用途 |
|------|------|
| `E:\webchat-ai\start-all.bat` | **一键开启**：输入联系人 + 发自我介绍 |
| `E:\webchat-ai\stop-all.bat` | **一键停止**：停止全部监听 |
| `E:\webchat-ai\start-all-quiet.bat` | 静默开启（需带联系人参数） |
| `E:\webchat-ai\stop-all-quiet.bat` | 静默停止 |

**建议：** 在桌面为 `start-all.bat` 和 `stop-all.bat` 各创建一个快捷方式。

### 6.2 Python 启动脚本

```powershell
# 交互式输入联系人（会发自我介绍）
python E:/webchat-ai/scripts/start_listen.py --interactive

# 指定联系人 + 自我介绍
python E:/webchat-ai/scripts/start_listen.py --private --contacts coco --welcome

# 指定联系人，不发自我介绍
python E:/webchat-ai/scripts/start_listen.py --private --contacts coco --no-welcome

# 从配置文件启动（见 listen-defaults.json）
python E:/webchat-ai/scripts/start_listen.py --all

# 已在运行时强制重启
python E:/webchat-ai/scripts/start_listen.py --private --contacts coco --welcome --force
```

### 6.3 Python 停止脚本

```powershell
# 停止全部
python E:/webchat-ai/scripts/stop_listen.py --all

# 停止指定私聊
python E:/webchat-ai/scripts/stop_listen.py --contacts coco

# 停止指定群
python E:/webchat-ai/scripts/stop_listen.py --groups 测试群1

# 只杀进程，不改暂停状态
python E:/webchat-ai/scripts/stop_listen.py --all --no-pause
```

### 6.4 PowerShell 脚本

```powershell
# 私聊监听
powershell -File E:/webchat-ai/scripts/listen-wechat.ps1 Air

# 群聊监听
powershell -File E:/webchat-ai/scripts/listen-wechat-group.ps1 测试群1

# 停止私聊（全部或指定）
powershell -File E:/webchat-ai/scripts/stop-wechat.ps1
powershell -File E:/webchat-ai/scripts/stop-wechat.ps1 coco

# 停止群聊
powershell -File E:/webchat-ai/scripts/stop-wechat-group.ps1 测试群1
```

### 6.5 恢复被暂停的联系人

若之前停止过监听，再次启动前会自动清除暂停标记。也可手动执行：

```powershell
python E:/webchat-ai/scripts/unpause_contacts.py coco
python E:/webchat-ai/scripts/unpause_groups.py 测试群1
```

## 七、配置文件说明

### 7.1 默认监听对象（可选）

**文件：** `E:/webchat-ai/config/listen-defaults.json`

```json
{
  "_comment": "使用 python start_listen.py --all 时读取",
  "interval": 15,
  "private_contacts": ["Air"],
  "groups": ["测试群1"]
}
```

> 日常使用推荐 **`start-all.bat`** 手动输入联系人；此文件主要用于 `--all` 或自动化脚本。

### 7.2 AI 模型配置

**文件：** `E:/webchat-ai/config/ai-config.json`

- 文字回复：`MiniMax-M2.5`（默认）  
- 图片识别：`MiniMax-M3`  
- 详见 `config/README.md`

### 7.3 状态文件（自动生成）

| 文件 | 说明 |
|------|------|
| `~/.wx4py-mcp/private_seen.json` | 私聊监听状态（暂停、已回复等） |
| `~/.wx4py-mcp/group_seen.json` | 群聊监听状态 |
| `~/.wx4py-mcp/memory/private/*.json` | 各联系人对话记忆 |
| `~/.wx4py-mcp/vision_cache/` | 图片识别缓存 |

## 八、常见问题

### Q1：双击 start-all.bat 没反应？

- 检查 Python 是否安装在默认路径  
- 右键「以管理员身份运行」试一次  
- 确认微信已登录  

### Q2：提示「private listener already running」？

- 已有监听在跑，先双击 **`stop-all.bat`**  
- 或使用：`python E:/webchat-ai/scripts/start_listen.py --private --contacts coco --force --welcome`

### Q3：找不到联系人 / 发送失败？

- 核对微信备注名是否完全一致（如 `coco` 不是 `Coco`）  
- 确保该联系人在微信左侧会话列表中可见  
- 微信主窗口不要被其他全屏窗口完全遮挡  

### Q4：监听启动了但不回复？

- 看后台窗口日志是否有报错  
- 确认 AI 配置：`python E:/webchat-ai/scripts/ai-config.py --status`  
- 确认最后一条是**对方发的**（左侧灰色气泡）  
- 若之前发过「停止监听」，需重新运行 `start-all.bat`  

### Q5：如何只监听、不发自我介绍？

```powershell
python E:/webchat-ai/scripts/start_listen.py --private --contacts coco --no-welcome
```

或使用 `listen-wechat.ps1`（本身不带自我介绍）。

### Q6：图片识别很慢？

可设置环境变量加速（可选）：

```powershell
$env:WX4PY_VISION_MAX_EDGE = "1280"
$env:WX4PY_IMAGE_SKIP_BLUR_CHECK = "1"
$env:WX4PY_IMAGE_PREVIEW_ZOOM = "0"
```

### Q7：停止后如何再开？

1. 双击 `start-all.bat`  
2. 输入联系人  
3. 回车即可
